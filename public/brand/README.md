# SightLine — Open line

Approved direction 02: the open S monogram, used only in black and white.

- `logo-black.svg` / `logo-white.svg`: horizontal logos with outlined lettering.
- `mark-black.svg` / `mark-white.svg`: transparent symbols.
- `app-icon.svg` / `app-icon-1024.png`: square white-on-black app artwork. The OS applies the corner mask.
- `wordmark-type.svg`: outlined Manrope lettering used to generate the lockups. License: `Manrope-OFL.txt`.

The symbol source is `lib/brand.json`. Run `npm run brand:generate` from the repo root to regenerate web, PWA, social, and mobile assets. Do not stretch the symbol, recolor it, or remove its internal opening. Keep at least 14% of the symbol's view box clear around it.
